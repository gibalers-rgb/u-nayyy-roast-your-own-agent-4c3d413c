A one-line roast of the AI agent my own team built, written by a small
deterministic Python program for the
[Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c)
bounty on make.fun.

## The roast

> My agent burned 56% of my weekly limit overnight, then lost a $500 bounty waiting on an approval card that never came — and billed me for the wait.

## How it works

`main.py` (Python 3.13, standard library only, no network, no secrets) writes
that single line to `/output/entry.txt`, validating that it is one line of
1–200 characters first.

Run it:

```sh
python3 main.py
```
